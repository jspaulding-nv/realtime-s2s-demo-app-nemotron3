# Public evaluation evidence

Only sanitized aggregate results belong in this directory. Raw audio, event
streams, full runtime logs, plots containing source titles, session IDs,
process IDs, transcripts, and absolute filesystem paths must remain outside
Git.

The current aggregate findings are documented in
[`NEMOTRON_TEST_RESULTS.md`](../../NEMOTRON_TEST_RESULTS.md). The latest
post-recovery staged canary is summarized in
[`STAGED_SAMPLE_02_RECOVERY_CANARY.md`](../STAGED_SAMPLE_02_RECOVERY_CANARY.md).
New evidence should use `long-form-01`, `long-form-02`, and `long-form-03` as
neutral sample IDs.
